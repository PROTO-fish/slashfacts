# Docs

- [`design.md`](design.md) — the gameplay rules and why they are what they are. Read before
  changing behaviour.
- [`architecture.md`](architecture.md) — code layout, storage, the mobile app, deployment.
- [`licensing-audit.md`](licensing-audit.md) — dependency licenses and F-Droid readiness.
- `fdroid/` — the F-Droid build recipe submitted to fdroiddata.
- `plans/` — implementation plans, current and past. Every plan starts with a `**Status:**`
  line (`Active`, `Completed`, or `Cancelled`) right under the title, updated in place as
  work progresses. Plans are never deleted or moved out once done — the folder is the
  history, not just the backlog.
- `adr/` — Architecture Decision Records: short, numbered documents capturing a significant
  technical decision and why it was made. See `adr/README.md`.
